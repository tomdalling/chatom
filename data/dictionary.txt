# Spelling Rulez
# - This is a phonetic alphabet. Knowing how a word is spelled tells you exactly how it's pronounced.
# - No 'c'. Hard 'c' -> 'k'. Soft 'c' -> 's'.
# - No 'y'. All 'y' -> 'i'.
# - No 'w'. All 'w' -> 'u'.
# - No double letters. "kill" -> "kil"
# - Graphemes are all single letters. No multi-letter sounds.
#   - "th" -> 'd'
#   - "sh" -> 's'
#   - "ph" -> 'f'
# - No weird extra vowels. "head" -> "hed"
# - TODO get rid of 'd' and replace with 't'?
